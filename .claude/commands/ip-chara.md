`ip-chara/BLUEPRINT.md` の「進め方と役割」の 4（基準の見直し）を行ってください。
画像の生成は Codex の担当なので、ここでは生成しない。

対象: $ARGUMENTS
（空欄なら、判定が付いている batch のうち、前回の見直し以降のもの）

手順:

1. 対象の `ip-chara/batch-*.md` から、A〜F の記号・判定・理由を集める
2. 次を短く集計する
   - 採用 / 保留 / 不採用の数
   - 採用と不採用で差が出ていない項目（判断に効いていない項目）
   - 理由の一言によく出る言葉（まだ項目になっていない判断の軸）
   - +α の入れ方（体の置き換え / 持ち物）と、掛け合わせの種類（道具・物・概念・事象）ごとの採用率
3. 集計をもとに `ip-chara/CRITERIA.md` の改訂案を作り、版数を上げて更新履歴に書く
4. 採用率がとても低い生き物・掛け合わせがあれば、`LISTS.md` での扱い（残す / 差し替え候補）を提案する。
   リストの途中の行は消さない（順番の規則がずれる）。差し替えは末尾への追加で行う

報告は「何が分かったか」と「基準をどう変えたか」を 5 行以内で。
