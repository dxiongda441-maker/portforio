# 副業計画：1ページサイト制作（2026-10 開始）

> 目標: 1か月で **最低 3万円 / 目標 10万円**。軍資金 3万円（ほぼ使わない）。
> 役割: Claude = 企画・制作・文面 / オルタ = 登録・送信・営業・顧客対応・入金。
> 進捗はこのファイルの「記録」に追記する（会話が切れても続きから再開できるように）。

## 狙う市場

**個人経営の整体院・リラクゼーションサロン**（1人〜少人数で運営している店）。

- 1人の新規客が数千円〜1万円を払う商売なので、サイトで月1〜2人増えれば元が取れる。この説明で営業できる
- ホットペッパーやエキテンの掲載だけで、自前のサイトを持たない店が多い（**未検証。営業リスト作りの段階で実数を数える**）
- 1ページで情報が完結する（悩み → 理由 → 料金 → アクセス → 予約）ので、短納期で量産しやすい

広告表現の注意: 「治る」「改善する」「効果がある」は書かない（整体は医療ではないため）。
「ケア」「施術」「お悩みに」と書く。お客様の声には「感じ方には個人差があります」を添える。

## 商品と価格

| プラン | 内容 | 価格 |
|---|---|---|
| **モニター価格**（先着3件） | 1ページサイト、スマホ対応、電話・LINE予約ボタン、Googleマップ | **19,800円** |
| 通常 | 同上 | 29,800円 |
| オプション | 写真の補正・トリミング | +5,000円 |
| 更新サポート | 料金や営業時間の書き換え（月2回まで） | 月3,000円 |

- モニター価格の条件: **実績として公開すること**と、**レビュー（感想）を書くこと**
- サーバー代: GitHub Pages / Netlify の無料枠で公開する。独自ドメインは店側の名義で取り、費用も店が払う（年1,000〜3,000円程度が目安。**取得前に要確認**）
- 納期: 素材（写真・文章のメモ）を受け取ってから **5日**
- 修正: 2回まで無料

### 売上の計算

- 3万円 = モニター2件（39,600円。ココナラ経由なら手数料を引いて約3万円）
- 10万円 = モニター3件 + 通常2件（約12万円）、または通常3件 + 更新サポート

### 「先に見本を作る」営業

返事が来た店、または特に脈がありそうな店には、**その店の名前と実際の料金で見本ページを作り、URLを送る**。
Claude が1件30分程度で作れるので、成約率を上げる一番の武器になる。
ただし、**相手の許可なく公開しない**（URLを知っている人だけが見られる状態で送る。断られたら消す）。
