# 副業計画：小さなお店の Instagram 運用代行 ＋ ホームページ制作（2026-10 開始）

> 目標: 1か月で **最低 3万円 / 目標 10万円**。軍資金 3万円（ほぼ使わない）。
> 役割: Claude = 企画・文章・制作・報告書・営業文 / オルタ = 登録・営業・顧客対応・画像の仕上げ・投稿・入金。
> 進捗はこのファイルの「記録」に追記する（会話が切れても続きから再開できるように）。
> 方針転換の経緯: `docs/decisions/0005`

## 狙う市場

**個人経営のカフェ・パン屋・焼き菓子店**（1人〜少人数で運営している店）。

選んだ理由:
- **資格も専門知識も要らない。** 医療・法律・整体のような広告の規制や専門用語がほぼない
- **Instagram が集客の主役の業種。** 「SNSをやった方がいい」と店主自身が分かっているので、説明の手間が少ない
- **写真の題材が毎日ある**（焼き上がり、新作、店内）。投稿のネタ切れが起きにくい
- 店主が忙しく、**「やりたいけど手が回らない」**状態の店が多い（**未検証。営業リスト作りの段階で、更新が止まっているアカウントの数を数える**）

弱点: 客単価が低く、予算が小さい店が多い。→ 月2万円からの安い価格で入る。

同じ商品が、そのまま **雑貨店・花屋・古着屋・ネイル/まつげサロン** にも使える（2本目の業種候補）。

## 市場調査（2026-10-09）

### 需要：「全部任せたい店」は少ない。「ネタと文章に困っている店」は多い

飲食店ドットコムの調査（2024年5月、飲食店経営者 393件、[記事](https://www.inshokuten.com/research/magazine/article/71)）:

| 項目 | 結果 |
|---|---|
| SNS を自店で運用している | 98.6% |
| 外部に委託している | **1.1%** |
| 委託していないし、今後も検討しない | 74% |
| 委託していないが、いずれ検討したい | **16.5%** |
| 困っていること 1位「投稿の内容やネタを考えること」 | **42.5%** |

読み取れること:
- **「全部代行します」だけでは、4店に3店は断る。** 刺さるのは「いずれ検討したい」の約6店に1店
- **一番の悩みはネタと文章。** → 「投稿は自分でやりたいが、ネタと文章が欲しい」店向けの安いプラン（月1万円）を足す
- 回答者は飲食店ドットコムの会員で、東京の店が多めという偏りがある

### 競合：クラウドソーシングは混んでいる。地元への直接営業は空いている

- SNS運用代行は「参入者が増えて競争が激しい」「投稿作成だけでは差別化しにくい」という記事が多い。ただし、**参入者数や応募数の統計は見つからなかった**（記事の多くは代行会社の宣伝）
- クラウドソーシングでは、安い案件ほど初心者が集まりやすいとされる。**実績ゼロでは、価格競争に巻き込まれる**
- 一方で、地元の個人カフェを訪問・DMで回る人は少ないと考えられる（**推測。2週目の営業で、断られた理由に「もう頼んでいる」が何件あるかで確かめる**）

### 結論

- **飽和しているのは「クラウドソーシングで、誰にでも同じ投稿作成を売る」市場。** ここは主戦場にしない
- **主戦場は地元の店への直接営業。** 「カフェ・パン屋専門」と業種を絞り、店ごとの見本を先に送って差別化する
- クラウドソーシングは「飲食店」「カフェ」と書かれた案件にだけ、1日数件応募する程度にとどめる

## バーを対象に入れるか → 1か月目は入れない

理由:
1. **営業できる時間が合わない。** バーは夜の営業で、昼の訪問ができない。客として行くとお酒代がかかる
2. **お酒の投稿には独自の注意点がある。** Instagram では酒類の写真やハッシュタグで投稿が削除された例が報告されている。年齢制限の設定も要る。「専門知識が要る業種は避けたい」という方針に合わない
3. **絞った方が営業文が強くなる。** 「カフェ・パン屋専門」と言える方が、店主に「うちの業界を分かっている人」と思われやすい

例外: **知り合いや行きつけのバーがあるなら、1件目として声をかける価値はある。** 知らない店への営業より、知人の紹介の方がはるかに決まりやすいため。
カフェで3件決まったら、2本目の業種としてバーや雑貨店を改めて検討する。

## 商品と価格

| 商品 | 内容 | 価格 |
|---|---|---|
| **ネタと文章のお届け**（ライト） | 投稿カレンダー（月8本分のネタ）、投稿文・ハッシュタグ。投稿は店主自身 | **月10,000円** |
| **Instagram運用**（本命・月額） | 月8投稿（企画・文字入り画像・文章・投稿）、ストーリー用の型、投稿カレンダー、月次報告。初月はプロフィール整備込み | **月20,000円〜** |
| ホームページ制作（入口） | 1ページサイト、スマホ対応、メニュー・営業日・地図、Instagram連携 | 19,800円〜 |
| セット | ホームページ ＋ 運用1か月目 | 初月29,800円、2か月目から月20,000円 |

- 見本: `samples/cafe/`（サイト）、`samples/cafe/instagram.html`（毎月渡すものの見本）、`samples/cafe/posts/`（投稿画像）
- 画像は Claude が `tools/insta-post/` のテンプレートから PNG で書き出す（Canva 不要）。Canva を使う場合は、claude.ai で Canva コネクタをつなげば Claude から操作できる
- 断られたらライトプランを提案する（「投稿はご自身で続けたい」店向け）
- **前払い**（月初に請求）。後払いだと1か月以内に入金されない
- **約束するのは作業量（月8投稿）。** フォロワー数や来店数の増加は約束しない
- 契約は「まず3か月」を勧める。ただし1か月ごとに解約できる形にして、敷居を下げる
- アカウントは**パスワードを預からない。** Meta Business Suite で担当者として追加してもらう
- 相場（参考）: 個人への依頼で月5万〜15万円程度という情報が多い（運用会社のブログ調べ。目安に過ぎない）。実績がないうちは安く入る

### 売上の計算

- 3万円 = 運用1件 ＋ サイト1件、またはセット1件
- 10万円 = 運用3件（6万円）＋ セット or サイト 2件（約4〜6万円）
- **2か月目以降**は、運用の件数 × 2万円が毎月入る（3件なら月6万円、5件なら月10万円）

### 「先に見本を作る」営業

脈のありそうな店には、**その店の実際の商品と言葉づかいで、投稿文を3本書いて送る**。
写真は店のアカウントにあるものを指さすだけにし、**無断で加工・転載しない**。
Claude なら1件15分程度で作れる。「この人に任せたら、こうなる」が一目で伝わるのが強み。

## 数字の目安（仮置き。実績が出たら書き換える）

| 指標 | 目標 |
|---|---|
| 連絡した店の数 | 2週間で 100件 |
| 返信・興味あり | 5〜10件 |
| 成約 | 3〜5件 |

返信率・成約率は**根拠のない仮の数字**。2週目の終わりに実数で見直す。

## 次の段階（2〜3か月目に検討）

- **AI活用の相談・講座**（お店向けに「ChatGPT / Claude で投稿文を自分で作る方法」を教える）。運用の実績ができてから
- **AI関連企業の SNS運用・営業の業務委託**への応募。運用の実績と、自分のアカウントがそのまま職務経歴になる
