## 1. ココナラ出品

**タイトル**（40字以内）
> 整体院・サロン向け｜スマホで予約が増える1ページサイト作ります

**サービス内容**

```
個人経営の整体院・リラクゼーションサロン向けに、
「悩み → 選ばれる理由 → 料金 → アクセス → 予約」が1ページでわかるサイトを制作します。

■ こんな方へ
・ホットペッパーやSNSはあるけど、自分のお店のページがない
・今のホームページがスマホで見づらい
・制作会社に頼むと高い（数十万円）と言われた

■ 含まれるもの
・1ページサイト（スマホ・PC対応）
・電話／LINE予約ボタン（スマホでは画面下に固定表示）
・Googleマップの埋め込み
・文章の作成（ヒアリングシートにお答えいただければ、こちらで書きます）
・公開作業（サーバー代は無料のサービスを使います）

■ 流れ
1. ヒアリングシートのご記入（10分ほど）
2. 写真をお送りいただく（スマホで撮ったもので大丈夫です）
3. 5日以内に初稿をお送りします
4. 修正2回まで無料 → 公開

■ 見本
{サンプルURL}

■ モニター価格について
先着3名様は、実績として掲載させていただくことを条件に 19,800円 で承ります。

■ ご用意いただくもの
・お店の写真（外観・内観・施術風景・スタッフ）3〜10枚
・料金表
・独自ドメイン（〇〇.com など）を使う場合は、取得費用（年1,000〜3,000円程度）
```

> ココナラは売上から販売手数料が引かれる。出品前に現在の料率を確認する。

## 2. 店舗への DM・問い合わせフォーム

```
{店名} ご担当者様

突然のご連絡失礼いたします。
{地域名}でWebサイト制作をしている{名前}と申します。

Googleマップで{店名}様を拝見し、口コミの評価がとても高いことが印象に残りました。
一方で、お店のホームページが見当たらなかったため、ご連絡いたしました。

整体院向けに、スマホから電話・LINEで予約しやすい1ページのサイトを作っています。
見本はこちらです → {サンプルURL}

今月はモニターとして、先着3店舗を 19,800円（通常29,800円）でお作りしています。
ご興味があれば、{店名}様の情報で見本を無料でお作りしてお見せすることもできます。
（ご依頼いただかなくても、費用は一切かかりません）

ご不要でしたら、このメッセージは読み流していただいて大丈夫です。
お忙しいところ失礼いたしました。

{名前}
{連絡先}
```

**送り分けのコツ**
- 1行目の「印象に残った点」は**必ず店ごとに変える**（口コミの内容、院長の経歴など）。全店同じ文面は読まれない
- 「ホームページが見当たらない」の部分は店の状況に合わせる: 「スマホで見ると文字が小さく」「予約ボタンが見つけにくく」など

## 3. 電話・訪問のトーク

```
お忙しいところすみません、{名前}と申します。
近くで小さなお店のホームページを作っている者です。
1分だけよろしいですか？

（OKなら）
{店名}さんの口コミを見て、すごく評判がいいなと思ったんですが、
ネットで探したときに、お店のページが見つからなかったんです。

整体院さん向けに、スマホから予約しやすいページを作っていまして、
今月はモニターとして2万円以下でお作りしています。

もしよければ、{店名}さんの情報で見本を無料で作って、
URLをお送りしてもいいですか？ 見てから決めていただければ大丈夫です。
```

- 施術中や混む時間帯（夕方以降・土日）は避ける。**平日の昼過ぎ**が無難
- 断られたら「失礼しました」ですぐ引く。その店には二度と連絡しない

## 4. クラウドソーシングの提案文

```
はじめまして、{名前}と申します。
ご依頼内容を拝見し、{依頼内容の要点}のサイト制作でお力になれると考えご提案します。

■ ご提案
{依頼に合わせた構成の案を2〜3行}

■ 制作例
{サンプルURL}
（スマホ表示を想定した1ページ構成です）

■ 納期・金額
初稿まで{N}日、{金額}円で承ります。修正は2回まで含みます。

■ 進め方
ヒアリング → 構成案 → 初稿 → 修正 → 公開 の順で、各段階でご確認いただきます。

ご不明な点があればお気軽にご質問ください。
```

- 「誰でも出せる定型文」は読まれない。**依頼文の具体的な一文に触れる**のが最優先
- 応募したい案件を見つけたら、依頼文を Claude に貼る → 提案文を作る、の流れが早い

## 5. ヒアリングシート（受注後に送る）

```
1. 店名・住所・電話番号・LINE公式アカウントのURL
2. 営業時間・定休日
3. 料金表（コース名・時間・価格）
4. 初回限定の特典はありますか？（例: 初回○○円）
5. どんなお客様に来てほしいですか？（年代・お悩み）
6. 他のお店と違うところを3つ（思いつく順で大丈夫です）
7. 院長・スタッフの紹介（経歴、施術で大切にしていること）
8. 実際のお客様の声（掲載の許可を取れているもの）
9. 好きな雰囲気・色（参考にしたいサイトがあればURL）
```
