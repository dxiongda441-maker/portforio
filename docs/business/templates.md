## 1. ココナラ出品（Instagram運用）

**タイトル**（40字以内）
> カフェ・パン屋さんのInstagram、毎月8投稿まるごと代行します

**サービス内容**

```
個人経営のカフェ・パン屋・焼き菓子店さま向けに、
Instagramの投稿を「企画 → 画像 → 文章 → 投稿 → 報告」までまとめてお引き受けします。

■ こんな方へ
・Instagramは作ったけど、忙しくて更新が止まっている
・何を投稿したらいいか分からない
・文章を考えるのが苦手

■ 毎月お渡しするもの
・投稿カレンダー（「この週はこの写真をください」まで書きます）
・投稿8本（文字入り画像・文章・ハッシュタグ）
・月次報告（数字と、来月やること）
・初月のみ：プロフィール文とハイライトの整備

■ お願いすること
・カレンダーに合わせて、スマホで写真を撮って送っていただくことだけです

■ 見本
{運用の見本URL}

■ 進め方
1. 30分ほどオンラインでお話を伺います（お店の雰囲気・お客様層）
2. プロフィールの改善案と、1か月目のカレンダーをお送りします
3. 投稿の前に、毎回文章をご確認いただきます

■ ご注意
・アカウントのパスワードはお預かりしません（Meta Business Suite で担当者として追加していただきます）
・フォロワー数や来店数の増加はお約束できません。お約束するのは、毎月の投稿と報告です
```

> ココナラの販売手数料は 22%（2026-10 時点の解説記事による。出品前に公式ヘルプで確認する）。
> 2万円で売ると手取りは約15,600円。**直接営業の方が手取りは多い。**

## 2. 店舗への Instagram DM

```
{店名}さま

突然のDM失礼いたします。{地域名}で、小さなお店のInstagramのお手伝いをしている{名前}と申します。

{具体的に良いと思った点：例「先週の栗のスコーンの投稿、断面の写真がとてもおいしそうでした」}

もし更新のお手間が負担になっていたら、投稿の企画から文章・画像づくりまで
まとめてお手伝いできます。店主さんにお願いするのは、写真を撮っていただくことだけです。

毎月お渡しするものの見本です → {運用の見本URL}

今月はモニターとして、先着3店舗を月2万円でお受けしています。
ご興味があれば、{店名}さんの投稿文の見本を3本、無料でお作りしてお送りします。

ご不要でしたら、このDMは読み流していただいて大丈夫です。
お忙しいところ失礼いたしました。
```

**送り分けのコツ**
- 2段落目の「良いと思った点」は**必ず店ごとに変える**。具体的な投稿に触れる。全店同じ文面は読まれない
- 「更新が止まっていますね」とは**書かない**（責められているように感じる）
- 1日に送るのは10件程度まで。短時間に同じ文面を大量に送ると、Instagram に制限される可能性がある

## 3. 訪問（客として行ったとき）

お会計のときなど、**店が空いているタイミングだけ**。

```
ごちそうさまでした。{商品名}、すごくおいしかったです。

実は私、近くで小さなお店のInstagramのお手伝いをしていまして。
もしよかったら、名刺だけ置いていってもいいですか？

（受け取ってもらえたら）
写真を撮っていただくだけで、文章や投稿はこちらでやる、という形です。
見本がこのURLにあるので、お時間あるときにでも見てみてください。
```

- 混んでいる時間（昼どき・週末）は避ける。**平日の14〜16時**が無難
- その場で売り込まない。名刺を渡して終わり。後日 DM で「先日お伺いした{名前}です」と送る
- 断られたら「失礼しました」ですぐ引く。その店には二度と連絡しない

## 5. クラウドソーシングの提案文

```
はじめまして、{名前}と申します。
ご依頼内容を拝見し、{依頼内容の要点}でお力になれると考えご提案します。

■ ご提案
{依頼に合わせた投稿の方向性を2〜3行。例：「新規のお客様向けに、メニュー紹介とお店の雰囲気を交互に投稿」}

■ 見本
{運用の見本URL}
（投稿カレンダー・投稿文・月次報告の例です）

■ 進め方
初回ヒアリング → 1か月分のカレンダー → 毎回の投稿前にご確認 → 月末に報告

ご不明な点があればお気軽にご質問ください。
```

- **依頼文の具体的な一文に触れる**のが最優先。定型文は読まれない
- 応募したい案件を見つけたら、依頼文を Claude に貼る → 提案文を作る、の流れが早い

## 6. ヒアリングシート（受注後に送る）

```
1. お店の名前・Instagramのアカウント名・ホームページ（あれば）
2. 営業時間・定休日・臨時休業の頻度
3. 人気メニュー ベスト3と、その理由（お客様によく言われること）
4. 季節の新作・限定品の予定（分かる範囲で）
5. どんなお客様に来てほしいですか？（年代・使い方：一人でゆっくり／テイクアウト など）
6. お店を始めたきっかけ・こだわり（材料、器、内装など）
7. 投稿で使ってほしくない言葉や、避けたい雰囲気
8. 好きなお店のInstagram（参考にしたいアカウントがあれば）
9. 写真を撮れる時間帯（仕込み中・開店前など）
```
