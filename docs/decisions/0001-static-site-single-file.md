# 0001. トップページを index.html 単体で完結させる

- **日付**: 2026-07-14（実装時点） / 2026-08-28（記録)
- **状態**: 採用（後片付けも完了）
- **関係する場所**: `index.html`, `style.css`, `main.js`

## 背景

初期版（〜2025-10）は `index.html` + `style.css` + `main.js` の 3 点構成で、
ネオン基調のデザイン、作品カードは `#projects-data` の JSON を `main.js` が
動的にレンダリングする方式だった。

2026-07 に「日本の四季・自然」を軸にしたデザインへ全面刷新した際、構成も変わった。

## 決めたこと

トップページを `index.html` 1 ファイルに閉じる。

- CSS は `<style>` ブロックにインライン化
- 作品カードは JSON からの動的生成をやめ、`<article class="project-card">` の HTML 直書きに
- 結果として `index.html` の `<script>` / `<link>` タグは **0 個**
  （2026-09 に favicon と canonical の `<link>` を追加。CSS/JS の読み込みは引き続き 0）

## 検討して捨てた案

- **外部 CSS/JS を維持する**: ファイルが分かれるぶん見通しは良いが、
  GitHub Pages に生 push する運用ではキャッシュ不整合が起きやすく、
  1 ファイルなら「push した内容 = 見える内容」が保証される。
- **JSON 駆動のカード生成を維持する**: 作品が 8 件程度で増減も稀なため、
  動的生成のメリットより JS 依存のデメリット（JS 無効時に作品が消える）が上回った。

## 結果と影響

- 編集箇所が 1 ファイルに集約され、迷わなくなった
- 反面 `index.html` は 821 行と大きい（2026-09-02 時点）。セクション単位で `grep -n '<section'` して辿る前提
- **後片付けは完了**: 参照されないまま残っていた `style.css`（383行）と `main.js`（155行）は、
  2026-09-02 の PR #3 で削除した。git 履歴には残っている（`git show 76ace1e:style.css`）。
