# 0004. 受託制作の見本サイトは `samples/` に置き、検索に載せない

- **日付**: 2026-10-09
- **状態**: 採用
- **関係する場所**: `samples/`, `docs/business/`

## 背景

副業として「個人店向けの1ページサイト制作」を始める（計画は `docs/business/plan.md`）。
営業で見せる見本サイトが必要になった。見本は架空の店舗で、住所や電話番号もダミー。

## 決めたこと

- 見本は `samples/<業種>/index.html` に置く。1ファイルで完結させる（CSS は `<style>`、`<script>` なし）。
- **`<meta name="robots" content="noindex">` を付け、`sitemap.xml` には載せない。**
- ページ最上部に「制作サンプルであり、店名・住所・電話番号・お客様の声は架空」と明記する。
- トップページの作品カードには（今は）追加しない。

## 検討して捨てた案

- **`projects/` に置く**: `projects/` は作品カードと 1:1 対応する作品置き場（`architecture.md`）。
  営業用の見本を混ぜると、その対応が崩れる。
- **sitemap に載せて検索に出す**: 架空の店舗が「実在の整体院」として検索に出ると、
  探している人を混乱させる。営業で URL を直接渡すだけなら、検索に載せる必要はない。
- **別リポジトリにする**: 管理が増える。同じ Pages で公開すればポートフォリオへの導線も作れる。

## 結果と影響

- 見本の URL は `https://dxiongda441-maker.github.io/portforio/samples/<業種>/`。
- 実際の顧客サイトはここに置かない（顧客ごとに別の公開先を用意する）。
- 実績が出たら、トップページに「制作実績」の作品カードを足すかどうかを改めて決める。
