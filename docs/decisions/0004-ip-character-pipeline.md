# 0004. IPキャラ設計図を ip-chara/ で運用し、画像は Canva で生成する

- **日付**: 2026-10-21
- **状態**: 一部置き換え済み（画像生成の担当と原寸の置き場所 → 0005）
- **関係する場所**: `ip-chara/`, `.claude/commands/ip-chara.md`

## 背景

手書きの「IPキャラ作成 設計図」（珍しい生き物 × 日常の道具・物・概念・事象でキャラを作り、
良いものだけ採用。出力はキャラクターデザインとリファレンスを画像で）に沿って作成を依頼された。
候補を何度も出して選ぶ運用なので、手順・候補・判定を残す場所と、繰り返し回す手段が要る。

## 決めたこと

- 設計図の清書と運用ルールを `ip-chara/BLUEPRINT.md`、候補は `ip-chara/batch-NNN.md` に連番で置く。
  採用可否は各バッチの「判定」欄で管理し、不採用も消さない（再提案防止）。
- 画像は Canva の画像生成で作る。リファレンスはデザイン画像を参照画像に渡して生成し、同一キャラを保つ。
- 原寸は Canva に置き、リポジトリには 200px の縮小版（`ip-chara/thumbs/`）とリンクだけ置く。
- 追加生成は `/ip-chara` コマンドで行う。

## 検討して捨てた案

- **SVG を手で描いてリポジトリに置く** — 原寸を手元に持てるが、漫画・アニメに使える画質にならない。
- **`projects/` に作品ページとして載せる** — 採用前の候補を公開することになる。依頼範囲を超えるので見送り。
- **原寸画像をリポジトリにコミット** — この環境から Canva の画像配信ドメインへの通信が遮断されていて取得できなかった。

## 結果と影響

- 縮小版しか手元にないので、原寸は Canva から手動でダウンロードする必要がある。
- `main` に入れると `ip-chara/` も GitHub Pages で公開される（リポジトリ全体を配信するため）。
  候補を非公開にしたくなったら、置き場所を見直す。
