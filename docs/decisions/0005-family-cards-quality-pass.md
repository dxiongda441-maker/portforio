# 0005. トランプゲーム集の品質改善: 効果音は合成、CPUの強さは3段階、ルール判定は外から検証できる形にする

- **日付**: 2026-09-26
- **状態**: 採用
- **関係する場所**: `projects/family-cards/core.js`, `projects/family-cards/app.js`, `projects/family-cards/games/*.js`

## 背景

初版（`0004`）の自己レビューで、次の弱点が見つかった。

- 音も振動もなく、自分の番が来ても気づきにくい。出したカードが再描画のたびに跳ね直す。
- CPU の強さが1種類だけで、子どもと大人が同じ卓で遊ぶと片方がつまらない。
- 大富豪の CPU は革命をほぼ出さない（30回戦で0回）。終盤に「2 と 3」が残っても弱い 3 から出す。
- 縛り・11バック・都落ちといった定番のローカルルールがない。
- ルール判定を直接テストする手段がない。

## 決めたこと

- **効果音は Web Audio で合成**する（音声ファイルを持たない）。メニューとゲーム画面で ON/OFF でき、設定は localStorage に保存する。
- 人間の入力待ちの間は操作パネルを金色に光らせ、番が来たら短いチャイムと振動（対応端末のみ）で知らせる。
- 場に出たカードは「出た直後 450ms だけ」跳ねる（`isFresh()` と `pop` クラス）。
- ゲーム定義に `levels: true` を付けると「CPUの強さ」を選べる。大富豪・七並べ・ポーカー・ダウト・ページワンが対応。
  - 大富豪の「つよい」は場に出たカードを数え、確実に勝てる組で主導権を取る。
  - ダウトの「つよい」は、めくられたカードがだれの手札に入ったかを覚える。
- ゲーム定義の `logic` に判定関数を載せ、ブラウザから直接テストできるようにする。
- 結果画面は同点を同順位で表示する（ランキングの `key` が同じなら同順位。家族ランキングの加点も同じ扱い）。

## 検討して捨てた案

- **案A: 効果音を mp3 で同梱** — 見た目以上にファイルが増え、著作権表記の管理も要る。短い効果音なら合成で十分。
- **案B: CPU の強さを席ごとに設定** — 画面が複雑になる。家族で遊ぶなら卓全体で1つの設定で足りる。
- **案C: テストを npm のテストランナーで書く** — ビルド工程・npm を入れない方針（`0001`）に反する。

## 結果と影響

- 大富豪の CPU 同士を 1200 局戦わせた平均順位（4人）: よわい 3.3位 / ふつう 2.2〜2.3位 / つよい 2.1〜2.2位。
  「つよい」と「ふつう」の差は小さい（約0.1位）ので、もっと差を付けたくなったら `cpuChoose` の hard 分岐を見直す。
- 革命は 1200 局中 151 回（約8局に1回）起きるようになった。
- ブラックジャックのスプリットは未実装のまま。
