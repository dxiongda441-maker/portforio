# 0005. IPキャラは Claude が企画、Codex が生成、人が判定する。組み合わせは機械的な順番で回す

- **日付**: 2026-10-21
- **状態**: 採用
- **関係する場所**: `ip-chara/BLUEPRINT.md`, `ip-chara/LISTS.md`, `ip-chara/CRITERIA.md`, `ip-chara/AGENTS.md`

## 背景

batch-001（6 体）を見て、画風と描き方を先に固定するべきだと分かった。一方で、
動物の特徴を優先し、掛け合わせを +α として足す方針は言葉で決めきれないので、数をこなして見つけたい。
画像の生成は Codex に回したい、という依頼があった。

## 決めたこと

- 役割: Claude = リスト・組み合わせ規則・判断基準 / Codex = 画像生成 / 人 = 判定。
- 生き物リスト（C01〜C12、必須特徴 3 つ付き）と掛け合わせリスト（P01〜P12、道具・物・概念・事象を順に並べる）を作り、
  ラウンド r で `C(i) × P((i + r) mod 12)` を機械的に組み合わせる。1 バッチ 6 体。
- 判断基準 v0.1: 必須 A（動物が分かる）・B（+α がパッと分かる）、評価 C〜F。3 バッチごとに見直す。
- 画風は未定。仮スタイルで統一し、batch-002 で 3 種類を試し描きする。
- 類似チェックは採用後に行う。世界観は未定（日常の風景にキャラを少しずつ出す使い方を想定）。
- batch-002 以降は原寸画像をリポジトリにコミットする。

## 検討して捨てた案

- **組み合わせを毎回人や Claude が選ぶ** — 好みに偏り、数もこなせない。依頼者が「機械的に順番に」と指定。
- **1 つの生き物に 6 種類の +α を当てて比べる** — +α の見せ方は比べやすいが、
  同じ動物が 6 体並び、画風や生き物の向き不向きの判断材料が増えない。ずらし方式なら数ラウンドで同じ比較もできる。
- **画風を先に決めてから生成する** — 出どころが未定。決まるのを待つより、試し描きで比べて決めるほうが早い。

## 結果と影響

- Codex に「次のバッチを作って」と言えば、番号と組み合わせが一意に決まる。
- リストの途中に行を挟むと過去バッチとの対応が崩れるので、追加は末尾のみ。
- Codex に画像生成の手段があるかは未確認。無ければ止まって報告する指示にしてある。
