# 0005. 統計クエストは security-quest のエンジンをコピーし、範囲を統計検定2級＋実務の判断に置く

- **日付**: 2026-10-23
- **状態**: 採用
- **関係する場所**: `projects/stats-quest/`、`docs/decisions/0004-security-quest-structure.md`

## 背景

`/learning-game` コマンドで、セキュリティ・クエストと同じ仕組みの学習ゲームを統計学で作った。
目標は「全章をクリアすれば分野をほぼすべて理解でき、状況を見て判断できる」こと。
統計学は「計算できる」と「結論が言えるかを判断できる」の間に大きな溝がある分野なので、範囲と問題の作り方を決める必要があった。

## 決めたこと

- **エンジンは `projects/security-quest/app.js` をコピー**し、分野固有の部分だけ書き換える。
  `STORAGE_KEY = "stats-quest-v1"`、`SAVE_PREFIX = "ST1."`、称号、導入文、最終ボス名、遊び方、修了証の参考リンク。
  データ形式・問題形式（6種）・CSP・非PWA は 0004 のまま。
- **範囲は 統計検定2級の出題範囲 ＋ 大学初年次の教科書1冊ぶん** を骨格にし、実務で避けて通れない
  重回帰・ロジスティック回帰・時系列・因果推論・ベイズの考え方・p値の誤用（ASA声明）を足した。4幕18章。
  - 第1幕 記述（データの種類／中心とばらつき／グラフ／2変数／データの集め方）
  - 第2幕 確率（確率とベイズ／確率変数と期待値／離散分布／連続分布と正規分布／標本分布と中心極限定理）
  - 第3幕 推測（推定と信頼区間／検定の論理／平均と比率の検定／クロス表・分散分析・ノンパラ）
  - 第4幕 モデルと判断（単回帰／重回帰とモデル選択／時系列と指数／因果推論と総合判断）
- 計算問題（`input`）は数表の値を問題文に書き、電卓だけで解けるようにする。数値の答えは scipy で検算した。
- 判断を問う問題を厚くする：誤った分析報告から誤りの行を選ぶ `spot`、p値・信頼区間の解釈、交絡・合流点・平均への回帰など。
- 誤答は学習者が実際に抱く誤解で作る（p値＝仮説の確率、r＝0.9 は90%説明、SD と SE の取り違え、期待値の回数で必ず当たる、など）。

## 検討して捨てた案

- **案A: エンジンを共通ファイル（例 `projects/_engine/app.js`）に切り出して2作品で共有** — 不具合の修正が1か所で済むが、
  security-quest に手を入れることになり、既存作品の動作確認をやり直す必要がある。今回は「同じエンジンをコピーして分野固有部分だけ替える」
  というコマンドの指示どおりにした。3作品目を作るときに改めて検討する。
- **案B: 範囲を統計検定2級だけに絞る** — 2級には因果推論・ロジスティック回帰・過学習・再現性の問題がほとんど含まれず、
  「状況を見て判断できる」目標に届かない。逆に、数理統計（尤度比検定の導出、多変量解析の数理）まで広げると
  クイズ形式で扱える範囲を超えるので入れなかった。
- **案C: 統計ソフト（R・Python）の操作を問う章を作る** — 手を動かさないと身につかない内容で、クイズでは「知識と判断の地図」までしか届かない。
  遊び方ページにその限界を明記し、修了証に公開データ（e-Stat）での練習を促す導線を置いた。

## 結果と影響

- 全18章・講義108枚・問題253問・用語300語。`node tools/check-learning-game.js stats-quest` で形式エラー0、正解が最長の選択問題 7%。
- **エンジンの不具合は2作品の `app.js` を両方直す必要がある**（コピーのため）。差分は `diff projects/security-quest/app.js projects/stats-quest/app.js` で確認できる。
- 時間で変わる内容は少ないが、宝くじの還元率の上限（当せん金付証票法）、日本のCPIの算式、ASA声明・心理学の大規模追試の要約を含む。改正・新しい声明があれば該当章を直す。
- 問題の追加は 0004 と同じく各章の `quiz` 配列の末尾に。
