# 0006. トランプゲーム集: ルールを家庭ごとに編集できるようにし、PWA にしてスマホで使えるようにする

- **日付**: 2026-09-30
- **状態**: 採用（`0004` の「SW を持たない」を置き換え）
- **関係する場所**: `projects/family-cards/`（`app.js` の設定画面、`games/*.js` の `options`、`sw.js`、`manifest.webmanifest`）

## 背景

- 大富豪をはじめ、トランプのルールは地域・家庭で違う。決め打ちのルールでは「うちのルールと違う」で遊べない。
- スマホで遊びたい、という要望。画面はもともとスマホ幅に対応していたが、ホーム画面から開いたり、
  電波のない帰省先で遊んだりはできなかった。

## 決めたこと

- ゲーム定義の `options` を拡張する。
  - `group: "local"` の項目は「ローカルルール」欄にまとめ、`help` の説明文を表示する。
  - `presets` でルールをまとめて切り替えられる（大富豪: かんたん／標準／ローカル全部入り）。「初期設定に戻す」もある。
  - ルール説明の先頭に「この卓の設定」を一覧表示し、初期設定から変えた項目は赤字にする。
- 追加したルール:
  - 大富豪: 革命・階段革命・階段・8切り・スペ3返しをそれぞれオン/オフ。5スキップ・7渡し・10捨て・反則上がりを追加。
  - 七並べ: トンネル（A と K がつながる）、パス1回。
  - ページワン: 2・2の重ね・8・J を個別にオン/オフ、特殊カードで上がれない、配る枚数。
  - ダウト: 1回に出せる枚数、ジョーカー。
  - ブラックジャック: ディーラーのソフト17、ブラックジャックの配当。
  - 神経衰弱: 「同じ数字＋同じ色」でペア、そろえたらもう一度の有無。
  - ハイ＆ロー: 同じ数字が出たときの扱い。
- PWA にする。`CACHE_PREFIX = "family-cards-"`。画面はネット優先、JS・CSS・画像はキャッシュ優先。
  メニューに「ホーム画面に追加」の手順（iPhone／Android）と、Android 用の追加ボタンを置く。

## 検討して捨てた案

- **案A: ルールを自由記述の JSON で編集させる** — 家族が使うには難しすぎる。ボタンで選ぶ形にした。
- **案B: ネイティブアプリ（App Store／Google Play）にする** — 審査・年会費・ビルド工程が要り、静的サイトの方針（`0001`）から外れる。PWA で「ホーム画面から全画面で開く」「オフライン」は満たせる。

## 結果と影響

- **`family-cards` のファイルを直したら `sw.js` の `CACHE_NAME` を上げる**必要ができた（CLAUDE.md のルール5の対象になった）。
- ダウトの CPU は「卓全体でダウトが起きる確率」が一定になるよう、1人あたりの確率を人数で割り戻すようにした
  （以前は CPU が多いほどほぼ確実にダウトされ、「2枚まで」設定で1局が数百手に長引いていた）。
- ネット越しの対戦（別々の端末で同じ卓に入る）は、静的サイトだけでは実現できないため未着手。
  実現するには中継サービス（例: Firebase Realtime Database）が要る。
