# 0006. 1か月目はバーを対象に入れず、月1万円のライトプランを足す

- **日付**: 2026-10-09
- **状態**: 採用
- **関係する場所**: `docs/business/plan.md`（「市場調査」「バーを対象に入れるか」）, `samples/cafe/instagram.html`

## 背景

オルタから「バーも対象に入れられないか」「Instagram運用代行は飽和していないか」と聞かれた。

## 決めたこと

- 1か月目の対象は、カフェ・パン屋・焼き菓子店のまま。**バーは入れない**（知人のバーへの声かけだけは例外として可）。
- 「ネタと文章のお届け（月1万円、投稿は店主）」をライトプランとして足す。
- 主戦場は地元への直接営業にする。クラウドソーシングは、飲食店の案件に絞って少しだけ応募する。
- 投稿画像は Claude が HTML テンプレート（`tools/insta-post/`）から PNG で書き出す。

## 検討して捨てた案

- **バーも対象に入れる**: 夜の営業なので昼に訪問できない。お酒の投稿は Instagram での削除例や年齢制限の設定があり、
  「専門知識の要る業種は避ける」方針に合わない。業種を絞った方が「専門」と名乗れて営業文が強い。
- **全部代行のプランだけで売る**: 飲食店ドットコムの調査（2024年5月）では、外部委託は 1.1%、
  「今後も委託しない」が 74%。一方で、悩みの1位は「ネタを考えること」（42.5%）。全部代行だけでは、断る店が多すぎる。
- **画像を Canva で作る**: このセッションでは Canva コネクタがつながっていない。
  HTML から PNG にすれば、つながっていなくても Claude だけで完結する。

## 結果と影響

- 断られた店にもライトプランを提案でき、最初の1件が取りやすくなる。
- カフェで3件決まったら、2本目の業種（バー・雑貨店など）を改めて検討する。
