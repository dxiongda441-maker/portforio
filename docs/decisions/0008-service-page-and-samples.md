# 0008. サイトの主目的を副業の営業に切り替え、`service/` と `samples/` を置く

- **日付**: 2026-10-31
- **状態**: 採用
- **関係する場所**: `service/index.html`, `samples/`, `index.html`

## 背景

試作として作ったポートフォリオは「Creative Developer / Artist」の作品集だった。
本人の方針として、今後は**個人事業主として仕事を受けるための営業ページ**を主目的にし、
転職用の実務の事例は副次的に載せることになった。本名は出さず「オルタ」名義のまま。

## 決めたこと

- 料金・見本・進め方・問い合わせは **`service/index.html`** に置く（同じサイトの別ページ）。
  トップページは「誰で何ができるか」を示して、ここへ送る。
- `service/` もトップと同じく **1ファイル完結・`<script>` 0 個**。
  `<meta http-equiv="Content-Security-Policy">` でスクリプトを全面禁止している。
- 営業用の見本（架空の店舗）は **`samples/<業種>/`** に置く。
  - `<meta name="robots" content="noindex">` を付け、`sitemap.xml` には載せない
  - ページ最上部に「制作サンプル・店名などは架空」と明記する
  - 作品カード（`projects/` と 1:1）には混ぜない。`service/` の「見本」から辿る
- 実際の顧客のサイトはこのリポジトリに置かない。

## 検討して捨てた案

- **サービス紹介をトップページそのものにする**: 作品・実務の事例・転職用の情報の置き場がなくなる。
  入口は1つ（トップ）にして、営業時は `service/` の URL を直接渡す。
- **見本を `projects/` に置く**: 作品カードと 1:1 の対応が崩れ、`tools/check.sh` の前提とも合わない。
- **別リポジトリ・別ドメインにする**: 管理が増える。同じサイトなら作品への導線も作れる。

## 結果と影響

- 営業の DM・チラシ・名刺には `…/service/` を載せる。
- 料金は `docs/business/plan.md`（非公開リポジトリへ退避済み）の 2026-10 時点の案をそのまま使っている。
  価格を変えたら `service/index.html` の「メニューと料金」と FAQ を両方直す。
- 問い合わせ窓口は Google フォーム（2026-10-31〜。サーバーを持たず、メールアドレスも公開しないため）。
  フォームの編集は本人の Google アカウントから行う。
