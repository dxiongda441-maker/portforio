# 0010. 「読んだものを覚える第2の脳」は LLM Wiki 方式で Vault 雛形に足す

- **日付**: 2026-11-03
- **状態**: 採用
- **関係する場所**: `docs/obsidian/vault-template/`, `docs/obsidian/SETUP.md`

## 背景

「読んだものを全部覚える第2の脳を5分で作る」手順が話題になっており、作れるか聞かれた。
既存の Vault 雛形には「判断・プロジェクト・日記」の層しかなく、読んだ記事や本を貯めて引く層が無かった。

## 決めたこと

Karpathy の LLM Wiki 方式を雛形に追加する。

- `30_Sources/` に原本を置く（Obsidian Web Clipper の保存先）。Claude は読むだけ
- `40_Wiki/` は Claude が書く。概念ページ・出典ページ・`index.md`（索引）・`log.md`（取り込み履歴）
- Vault 用コマンド `/ingest`（取り込み）`/ask`（出典つき回答）`/lint`（点検）を `.claude/commands/` に置く
- 矛盾は上書きせず併記する。推測は明記する

## 検討して捨てた案

- **RAG（ベクトル検索）を組む**: 埋め込み・DB が要り「ビルド工程なし」の方針と合わない。数百ページまでは索引＋grep で足りる
- **原本を Claude に直接 grep させるだけ**: 毎回読み直しになり、読んだもの同士のつながりが蓄積しない
- **この portforio リポジトリに Wiki 本体を置く**: 公開リポジトリなので個人の読書記録を置けない。置くのは雛形だけ
- **新しい private リポジトリをこのセッションで作る**: 作業環境からリポジトリを作成できないため見送り。ユーザーが作る

## 結果と影響

雛形をコピーして Web Clipper の保存先を設定すれば、すぐに使い始められる。
ページが数百を超えて `index.md` で当たりがつかなくなったら、検索の仕組みを見直す。
