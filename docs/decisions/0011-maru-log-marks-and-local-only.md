# 0011. ○△× 記録帳 Maru Log は、Glow Log と同じく端末内（IndexedDB）だけに保存し、項目は利用者が編集する

- **日付**: 2026-11-07
- **状態**: 採用
- **関係する場所**: `projects/maru-log/`

## 背景

本人が手書きの日記で、毎日の重要事項（アウトプット・SNS・英語・瞑想など）を ○△× で付けている。
これを仕事・副業・趣味・学びの記録帳としてアプリでも付け、続き具合を振り返りたいという依頼。
「Glow Log と同じ仕組み（PWA・端末内保存）で」という指定があった。
Glow Log（`claude/self-improvement-tracker` ブランチ、未取り込み）の決定 0010 は、そのブランチでしか読めない。

## 決めたこと

- `projects/maru-log/` に PWA として置く。保存先は IndexedDB（DB名 `maru-log`、`days` と `meta`）。SW の `CACHE_PREFIX` は `maru-log-`。
- `<meta>` の CSP で外部通信を禁止（Glow Log と同じ）。日記の中身はどこにも送らない。
- 評価は 3 段階：○＝2点・△＝1点・×＝0点。**空欄は「未記入」として点数の分母に入れない**（付け忘れを × と混ぜない）。
- 項目は設定で追加・改名・並べ替え・休止・削除できる。各項目に ○△× の**基準**を書ける（日によって甘くなるのを防ぐ）。
  初期値は依頼にあった 4 つ（アウトプット・SNS 発信・英語・瞑想）＋仕事・趣味に 1 つずつ。
- 手書き日記からの転記用に「月の表」を作る。マスをタップするたびに ○→△→×→空欄 と切り替わる。
- 振り返りはルールベース（達成度の上下・3日続けて×・曜日の傾向など）。AI へは文章をコピーして本人が渡す方式（Glow Log と同じ）。
- 決定番号は 0011。0010 は未取り込みの Glow Log ブランチが使っているため、合流時の衝突を避けた。

## 検討して捨てた案

- **Glow Log に「習慣」タブとして足す**: Glow Log は体と見た目の記録で、写真まで含む。日記の習慣は性質が違い、画面も重くなる。別アプリにした。
- **Glow Log のブランチから派生させる**: 未取り込みのブランチに依存すると、片方だけ main に入れたいときに困る。main から独立に作った。
- **○×の 2 段階**: 手書き日記で △ を使っているとのことなので 3 段階にした。
- **localStorage に保存**: 容量は足りるが、Glow Log と仕組みをそろえる指定があり、項目と日ごとの記録を分けて持てる IndexedDB にした。

## 結果と影響

- 端末を変える・ブラウザのデータを消すと記録が消える。設定から JSON（全部）/CSV（表計算用）を書き出せる。読み込みは日付・マス単位の合流。
- 項目を「削除」すると過去のマスも表に出なくなる（データ自体は残り、書き出しにも入らない）。残したいときは「休止」を使う。
- 将来 Cloudflare へ移す（0009）とオリジンが変わり、IndexedDB は引き継がれない。移行前に書き出し→読み込みが必要。
- Glow Log と同時に main へ入れる場合、トップの作品カード番号（どちらも 12）と作品数の文言（12作品）、docs の件数がぶつかる。合流時に 12/13 に振り直す。
