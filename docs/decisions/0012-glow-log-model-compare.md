# 0012. 「お手本と比べる」は Glow Log のタブとして作り、画像の取り込みと判定は本人の手で行う

- **日付**: 2026-11-28
- **状態**: 採用
- **関係する場所**: `projects/glow-log/`

## 背景

本人が、目標にしたい人物（芸能人など）の画像や動画をインスタやネットから読み込み、自分と比べて改善点を指摘するツールを求めた。
自分の顔と体の写真はすでに Glow Log が端末内（IndexedDB）に持っていて、写真の撮り方の決まりや、Claude への相談文を作る仕組みもある。

## 決めたこと

- 新しいアプリを作らず、Glow Log に「お手本」タブを足す。データは IndexedDB の `meta["model"]` に1人分。
- お手本の画像は、本人が保存した画像・スクショを選ぶか、動画を再生して止めた場面を切り出す（canvas で JPEG 化）。
- 比べ方は「並べる」「重ねる（濃さ・大きさ・位置を調整）」。Claude に1枚で送れるよう、左右に並べた JPEG を書き出す。
- 改善点の判定はアプリ内でせず、お手本のメモ・自分の記録・自己チェックを依頼文にまとめ、本人が画像と一緒に Claude に送る。
- 比べるのは変えられるもの（髪・眉・ひげ・肌・体・服・表情・姿勢）だけ。顔立ち・骨格は項目に入れない。
- 特定の人物のプロフィールや画像はコードに入れない。お手本の中身は本人が入力する（調べたメモは非公開のノートに置く）。

## 検討して捨てた案

- **Instagram・ネットから URL で自動取り込み**: ログインが必要で、自動取得は Instagram の規約に反する。CSP で外部通信を禁止している方針（0010）とも合わない。
- **アプリ内で AI に判定させる（Claude API を直接呼ぶ）**: 静的サイトに API キーを置くと誰でも使えてしまう。サーバーを立てるとビルドなし・外部通信なしの方針に反する。
- **顔の特徴点を計測して数値で比べる（MediaPipe など）**: 外部ライブラリの読み込みが必要で、変えられない骨格の差を強調してしまう。
- **独立した新しいアプリにする**: 自分の写真の保存・撮影・書き出しを作り直すことになり、写真が2か所に分かれる。
- **お手本（平野紫耀さん）のプロフィールを初期データとして同梱**: 公開リポジトリに特定の個人を目標にした内容が載り、作品として汎用でなくなる。

## 結果と影響

- 画像の保存とスクショは本人の手作業になる。そのぶん、規約や著作権の扱いは「本人が端末の中だけで使う」範囲に収まる。
- お手本の画像も書き出しファイルに入るので、書き出したファイルを他人に渡さない注意が要る。
- お手本は1人分だけ。複数人を切り替えたくなったら `meta["model"]` を配列にする。
