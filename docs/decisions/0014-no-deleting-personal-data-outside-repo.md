# 0014. リポジトリの外にある本人のデータは、AI に削除させない

- **日付**: 2026-11-16
- **状態**: 採用
- **関係する場所**: `.claude/settings.json`, `CLAUDE.md`（個人設定 → 進め方）

## 背景

2026-11-13 未明（日本時間）ごろ、Google カレンダーの 8月〜11月の予定がまとめて消えた。
行動記録（ライフログ）として使っていた予定で、11-16 に本人がゴミ箱から復元した（8〜10月で 250 件以上）。

どの AI・どのチャットが消したかは特定できていない。同じ時期に Claude（定期タスクを含む）と
Meta の Muse の両方を Google カレンダーにつないでいた。本人は Claude 側が原因と見ている。

「確認不要で最後まで進めてよい」という個人設定は、リポジトリ内のファイルを想定したもので、
カレンダーやメールのような外のデータには歯止めが書かれていなかった。

## 決めたこと

- `.claude/settings.json` の `permissions.deny` で、次のツールを**実行できなくする**。
  - Google カレンダーの予定の削除（`delete_event`）
  - Gmail のゴミ箱移動（`trash_message` / `trash_thread`）
  - Google Drive のゴミ箱移動（`trash_file`）
- カレンダーの予定の変更（`update_event`）は `ask`（毎回確認）にする。
- `CLAUDE.md` の「実行前に必ず確認を取る」に、外部データの削除・一括変更を足す。
- 消す必要があるときは、本人が Google の画面で消す。AI は対象の一覧を出すところまで。

## 検討して捨てた案

- **CLAUDE.md にルールを書くだけ**: 文章のルールは読み飛ばしや解釈違いで破られる。
  設定で実行そのものを止める方が確実なので、両方入れた。
- **カレンダーの連携を外す**: 朝のやること通知や時間記録の取り込みが止まる。読み取りと作成は残したい。
- **カレンダーのバックアップをこのリポジトリに置く**: 公開リポジトリなので個人の行動記録は置けない。
  バックアップは非公開側（ライフログの週次バックアップ）に足すのが筋。未実施。

## 結果と影響

- この設定が効くのは**このリポジトリを開いた Claude Code のチャットだけ**。
  ほかのリポジトリ（非公開のライフログ用など）、リポジトリなしのチャット、定期タスク、Cowork、
  Muse・Codex・Gemini には効かない。全体に効かせるには、本人が各サービスの連携設定で
  削除の権限を「毎回確認」か「オフ」にする（Claude は claude.ai/customize/connectors）。
- 設定は `main` に入るまで、新しいチャットには反映されない。
- Google カレンダーのゴミ箱は約30日で空になる。消えたことに気づくのが遅いと戻せない。
