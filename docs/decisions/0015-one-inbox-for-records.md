# 0015. 振り返り・支出・やることの入力先を「ライフログの受付箱」1か所にする

- **日付**: 2026-11-21
- **状態**: 採用
- **関係する場所**: artifact「ライフログ」（ホームの受付箱・collection `inbox`）, `CLAUDE.md`（個人設定）

## 背景

振り返り・支出・やってほしいことを、どこに入れればよいか毎回迷っていた。
チャットで話した振り返りが保存されないこともあった（11/6〜11/16 の振り返りが残っていなかった）。
原因は、チャットごとに「記録を保存する」指示があったり無かったりしたこと。

## 決めたこと

- 入力先は **ライフログのホームにある「受付箱」** 1か所。文章・音声入力・写真・動画（1つ20MBまで）を送れる。
- 受付箱に入ったものは、定期の仕分けで家計簿（`tx`）・振り返り（`posts`）・やること帳（`tasks`）へ振り分ける。
- チャットで話してもよい。その場合もチャットが受付箱へ保存する。このリポジトリの `CLAUDE.md` にそのルールを書いた。
  リポジトリを開かないチャットには、claude.ai の個人設定に同じ文を入れてもらう。

## 検討して捨てた案

- **専用チャットを1つ決める**: 長く使うと会話が上限に達して止まる（カード通知の定期タスクで起きた）。
  データの置き場にならない。
- **新しいページを作る**: すでにライフログ・やること帳・確認箱・スケジュールがあり、入口をこれ以上増やさない。
- **受付箱から直接やること帳だけに入れる**: 支出と振り返りを分けられない。仕分けを挟む方が入力が楽。

## 結果と影響

- 仕分けの定期タスクは、自動の許可チェックで作成を止められており、まだ動いていない。
  動くまでは、受付箱は「ためておく場所」で、振り分けはチャットで頼む必要がある。
- 写真は、仕分けの際に Claude が画像を読む必要がある。読めないものは「要確認」に回す。
