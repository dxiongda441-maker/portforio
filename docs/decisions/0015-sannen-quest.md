# 0015. 若手の「実績がない」を解くゲームは、学習ゲームのエンジンを使わず選択型シミュレーションで作る

- **日付**: 2026-11-28
- **状態**: 採用
- **関係する場所**: `projects/sannen-quest/`

## 背景

YouTube 企画のリサーチ（2026-11-27〜28 のチャット）で、入社5年以内の若手の課題を調べた。
最も根拠が厚かったのは「成長実感がない・社内で実績を残せない（3年目の壁）」。
これを解決するゲームを作ってほしいと依頼された。課題の絞り込みは任されていた。

## 決めたこと

- 課題は「成長実感がない・実績を残せない」に絞る。辞めるか迷う・AI への不安・上司との関係は、出来事として組み込む。
- 形式は **12週間の選択型シミュレーション**。行動を選んで「実績の種」を作り、記録して実績に変える。
  記録の3択で「工夫＋Before→After の数字」の書き方を体で覚えさせる。
- エンディングは **★3 の実績の件数**を中心に判定する。★1 を数だけ集めても良い結末に届かないようにした
  （初版では数で届いてしまったため、自動プレイの結果を見て変えた）。
- ゲームの外に **実績メーカー**を付け、自分の本当の仕事を1行にできるようにする。入力は端末内（localStorage）だけに保存する。
- Service Worker は付けない（ルール5の管理対象を増やさないため）。CSP で外部通信を禁止する（0014 の方針どおり）。

## 検討して捨てた案

- **`/learning-game` のエンジン（security-quest 系）で作る** — 知識を18章で網羅する作りで、
  「行動を変える」ことが目的の今回の課題には重すぎる。クイズで知識を問うより、選択と結果で判断の癖をつける方が合う。
- **お金・副業を題材にする** — 需要は大きいが、YouTube でも強い競合がいる分野で、ゲームで解ける部分が少ない。
- **上司との関係を主題にする** — 相手しだいの部分が大きく、プレイヤーの行動だけで解決する形にしにくい。

## 結果と影響

- 遊ぶと「記録しないと実績は消える」「数字と工夫で書く」が残るようにした。
- 解説の数値は企業の PR 調査や記事の要約を経由したものが多い。動画などに転用する前に原典を確認する必要がある。
- エンディング「どちらも選べる人」「社外でも通用する」は自動プレイでは到達を確認していない（条件上は到達可能）。
