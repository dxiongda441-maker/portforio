# 0016. 複数の AI の共通前提は D:\AI-Share\AI_CONTEXT.md 1枚にまとめる

- **日付**: 2026-11-27
- **状態**: 提案（PC での動作は未確認）
- **関係する場所**: `docs/ai-share/`・`tools/setup-ai-share.ps1`

## 背景

Claude Code・Codex・Gemini・Meta の Muse を併用していて、毎回同じ前提（自分のこと・答え方の好み・どこに何があるか）を送り直している。

## 決めたこと

- 前提の本体は `D:\AI-Share\AI_CONTEXT.md` の1枚だけ。
- 各 AI が自動で読むファイル（`CLAUDE.md`・`AGENTS.md`・`GEMINI.md`）は本体を指すだけにし、中身を書かない。
- 雛形だけ公開リポジトリに置き、埋めたものは D: に置く（本名・お金・健康の話が入るため）。

## 検討して捨てた案

- **AI ごとに同じ内容を書く** — 1か所を直すと他と食い違う。
- **埋めた本体を portforio に置く** — 公開リポジトリなので個人情報が出る。
- **最初から非公開リポジトリに置く** — クラウドからも読めるが、Codex に家計データまで見せることになる（ai-office と tsumiage-private を分けている理由と同じ）。D: で困ったら移す。

## 結果と影響

PC の AI は同じ前提で動ける。クラウド版 Claude とブラウザ版の AI からは D: が見えないので、添付か Remote Control が要る。
