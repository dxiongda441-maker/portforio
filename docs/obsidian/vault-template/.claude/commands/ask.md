質問: $ARGUMENTS

1. `40_Wiki/index.md` を読み、関係しそうなページに当たりをつける。
2. 足りなければ `grep -ril "キーワード" 40_Wiki/` で探す。それでも無ければ `30_Sources/` を grep する。
3. 読んだページだけを根拠に答える。文ごとに `[[ページ名]]` で出典を示す。
4. Wiki に無いことは「Wiki には無い」とはっきり言う。一般知識で補う場合は、補った部分を分けて書く。
5. 答えが今後も役立ちそうなら、`40_Wiki/` に新しいページとして保存するか提案する（保存はユーザーの了承後）。
