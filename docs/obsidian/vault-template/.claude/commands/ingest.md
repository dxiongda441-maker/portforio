description: 30_Sources/ の未取り込みの資料を 40_Wiki/ に整理して取り込む
---

`30_Sources/` のうち `40_Wiki/log.md` に記録が無いファイルを取り込む。
引数があればそのファイルだけを対象にする: $ARGUMENTS

ファイル1つずつ、次の手順で進める。

1. 原本を読み、要点を3〜5行で日本語にまとめてユーザーに示す。
2. `40_Wiki/index.md` を読み、関係する既存ページを特定する（Wiki 全体は読まない）。
3. ページを更新または作成する。
   - 出典ページ `40_Wiki/sources/<短い名前>.md` を作る（要約・要点・原本へのリンク `[[30_Sources/…]]`）
   - 登場する概念・人物・道具ごとのページ `40_Wiki/<名前>.md` に追記する。無ければ作る
   - 追記した文には必ず出典リンクを付ける
   - 既存の記述と矛盾したら、上書きせず「⚠️ 矛盾」として両方を併記する
4. `40_Wiki/index.md` に新しいページを1行ずつ足す。
5. `40_Wiki/log.md` の末尾に、取り込んだファイル・作成/更新したページ・矛盾を追記する。

守ること:
- `30_Sources/` の原本は**絶対に書き換えない・消さない**
- 原本に書かれていないことを書き足さない。推測は「（推測）」と明記する
- 1回の取り込みで更新するページは10枚程度までにとどめる
