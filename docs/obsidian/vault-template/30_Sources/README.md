# 30_Sources — 読んだものの原本置き場

記事・論文・メモ・書き起こしを**そのまま**置く場所。Claude はここを**読むだけで書き換えない**。

- 置き方: Obsidian Web Clipper の保存先をこのフォルダにする（ブラウザでクリップするだけ）
- PDF や手書きメモの写真もそのまま置いてよい
- ファイル名は自由。整理は `/ingest` で Claude が `40_Wiki/` 側に行う

取り込み済みかどうかは `40_Wiki/log.md` に記録される。
