# Vault メモリ

<!-- ✏️ 自己紹介を1〜2行。毎回説明しなくて済むように -->
個人の知識・制作ノートを置く Obsidian Vault。

## 地図

| 探すもの | 場所 |
|---|---|
| 全体の索引 | `00_Index/MOC.md` |
| 過去の判断と理由 | `10_Decisions/` を grep |
| プロジェクト別の文脈 | `20_Projects/<名前>/` |
| 日々の記録 | `90_Daily/YYYY-MM-DD.md` |

> **Vault 全体を読まないこと。** まず `00_Index/MOC.md` を見て、
> 必要なディレクトリだけ grep する。全部読むとコンテキストを浪費して精度が落ちる。

## 常に守るルール

<!-- ✏️ ここが一番効きます。毎回言っていることを書いてください -->

1. 応答は日本語。
2. 新しいノートは既存のフォルダ構造に従って置く。勝手に新フォルダを作らない。
3. ノート冒頭には YAML フロントマターで `date` と `tags` を付ける。
4. 既存ノートを書き換える前に、何をどう変えるか示す。
5. 出典が不明な情報は「出典不明」と明記する。創作しない。
