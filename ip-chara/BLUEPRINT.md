# IPキャラ作成 設計図

> 手書きの設計図（2026-10-21）を清書し、実際に回せる手順に落としたもの。
> キャラの候補一覧は `batch-NNN.md`、追加生成は `/ip-chara` コマンドで行う。

## 目的

独自のかけ合わせによって独自の IP キャラクターを作成し、
それを AI で作成する漫画やアニメで活用していく。

## 作り方

1. **ベース = あまり知られていない珍しい生き物**を優先して使う（独自性を強めるため）。
2. ベースに **日常の「道具」「物」「概念」「事象」** のどれかをかけ合わせてキャラを作る。
3. 候補を複数作ってもらい、**良かったものだけ採用**する。
4. 出力は **キャラクターデザイン** と **リファレンス** を画像で行う。

設計図の例:

| ベース | かけ合わせ | キャラ |
|---|---|---|
| 犬 | 火 | 火をまとった犬 |
| 熊 | 炭 | 一度熱を込めると長時間保温される熊 |
| 亀 | 鍋 | 甲羅が鍋の亀 |

## かけ合わせのルール（運用で決めたこと）

- **かけ合わせは見た目だけで終わらせない。** 道具・物の「機能」や概念・事象の「性質」を、
  キャラの**能力**と**弱点（代償）**の両方に落とす。弱点があると漫画の話が作れる。
- **ベースの生き物の実際の生態を 1 つ拾う。** 例: アイアイが木を叩いて虫を探す → 鍵穴を叩いて開ける。
  生き物の知名度が低いぶん、生態ネタが「へぇ」になって独自性が上がる。
- 1 回の生成で **道具・物・概念・事象を混ぜる**（偏ると似たキャラばかりになる）。
- 名前は **カタカナ 4〜6 字**、ベースとかけ合わせの両方が連想できるもの。

## 1 体あたりの成果物

| 成果物 | 中身 | 縦横比 |
|---|---|---|
| キャラクターデザイン | 全身 1 体・正面寄りの 3/4 ビュー・無地背景 | 1:1 |
| リファレンス | 上段: 正面 / 側面 / 背面（同スケール）、下段: 表情 4 種 + カラースウォッチ | 16:9 |
| 設定 | 名前・ベース・かけ合わせ・能力・弱点・性格・デザインの要点・配色 | テキスト |

リファレンスは**キャラクターデザイン画像を参照画像として渡して**生成する（別々に作ると別キャラになる）。

## 画像プロンプトの雛形（英語のほうが安定する）

**キャラクターデザイン**

```
Original anime-style mascot character design, single full-body front three-quarter view,
centered, plain off-white background, no text. "<名前>": a <生き物の英名>
(<見た目の特徴を 1 行>) fused with <かけ合わせ>. <かけ合わせが体のどこにどう現れるか>.
<性格が出る表情・ポーズ>. Clean line art, soft cel shading, palette: <色 3 つ>.
Character design for manga and anime.
```

**リファレンス**（上の画像を参照画像に指定）

```
Character reference sheet (turnaround model sheet) of this exact same character: <特徴の要約>.
Layout on plain white background: top row full-body front view, side view, back view at the
same scale; bottom row four facial expressions (<表情 4 つ>) as head close-ups, plus a row of
flat color swatches. Clean anime line art, soft cel shading, consistent proportions and colors.
No text, no labels.
```

## 採用の流れ

1. `batch-NNN.md` の各キャラの「判定」を `候補` → `採用` / `保留` / `不採用` に書き換える。
2. 採用したキャラは、漫画・アニメで使う前に**同じ参照画像から追加のポーズ・表情**を作って固める。
3. 不採用でも記録は消さない（同じかけ合わせを再提案しないため）。

## 画像の置き場所

- **原寸画像は Canva に保存されている**（各キャラのリンクから開いてダウンロード）。
- `thumbs/` は一覧で見分けるための縮小版（200px）。生成ツールの都合で原寸はこの環境から取得できなかった。
