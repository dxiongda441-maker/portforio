# IPキャラ作成 設計図

> 手書きの設計図（2026-10-21）を清書し、実際に回せる手順に落としたもの。

## 目的

独自のかけ合わせによって独自の IP キャラクターを作成し、
それを AI で作成する漫画やアニメで活用していく。

## 作り方（設計図の原文）

1. **ベース = あまり知られていない珍しい生き物**を優先して使う（独自性を強めるため）。
2. ベースに **日常の「道具」「物」「概念」「事象」** のどれかをかけ合わせてキャラを作る。
3. 候補を複数作ってもらい、**良かったものだけ採用**する。
4. 出力は **キャラクターデザイン** と **リファレンス** を画像で行う。

設計図の例: 火 × 犬 = 火をまとった犬 / 炭 × 熊 = 一度熱を込めると長時間保温される熊 / 鍋 × 亀 = 甲羅が鍋の亀

## スタイルの軸（2026-10-21 決定）

- **動物の特徴が主役。** 生き物ごとの必須特徴（見た目 3 つ）は必ず残す。
- **掛け合わせは +α。** 体の一部の置き換えか持ち物として、パッと見て分かる形で 3 割程度に入れる。
- +α の入れ方は言葉で決めきれないので、**数をこなして判定の中から見つける。**
- 画風の出どころは**未定**。決まるまでは `AGENTS.md` の仮スタイルで統一し、batch-002 で 3 種類を試し描きして比べる。

## 進め方と役割

| 段階 | 担当 | やること | 置き場所 |
|---|---|---|---|
| 1. 企画 | Claude | 生き物リスト・掛け合わせリスト・順番の規則、判断基準を作る | `LISTS.md` `CRITERIA.md` |
| 2. 生成 | Codex | 規則どおりに 6 体ずつ、デザインとリファレンスの画像を作る | `batch-NNN.md` `images/` |
| 3. 判定 | 人 | 判断基準で採用 / 保留 / 不採用を付け、理由を一言書く | `batch-NNN.md` |
| 4. 基準の見直し | Claude | 3 バッチごとに判定を集計し、基準とリストを直す（`/ip-chara`） | `CRITERIA.md` |
| 5. 類似チェック | Claude | 採用したキャラだけ、既存のキャラ・名前との類似を調べる | （採用後に決める） |

Codex への具体的な指示は `AGENTS.md`。

## 世界観メモ（未確定）

  そのため掛け合わせは家・学校・街角にあるものから選び、判断基準に「日常に置けるか（D）」を入れた。
