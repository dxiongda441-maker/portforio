# 判断基準（v0.2）

画像を見て**採用 / 保留 / 不採用**を決めるための基準。最初の仮版で、判定を重ねながら直していく。
数をこなすため、1 体 30 秒で付けられる粒度にしている。

## 必須（どちらかが × なら不採用）

| 記号 | 見るところ | ○ の条件 |
|---|---|---|
| **A** | 動物が分かる | +α を手で隠しても、元の生き物だと分かる（`LISTS.md` の必須特徴 3 つが残っている） |
| **B** | +α がパッと分かる | 説明を読まずに 3 秒で「何と掛け合わせたか」が分かる |

## 評価（○ = 2 / △ = 1 / × = 0）

| 記号 | 見るところ | ○ の条件 |
|---|---|---|
| **C** | 動物が主役 | +α が体の一部の置き換えか持ち物で、全体の 3 割程度に収まっている |
| **D** | 日常に置ける | 台所・公園・通学路の風景に置いても浮かない（大きさ・質感） |
| **E** | 何度でも描ける | 形が単純で、リファレンスとデザインの見た目が一致している |
| **F** | 好き | 直感。理由は書かなくてよい |
| **G** | 神秘的 | 民話の守り神や精霊のような、少し人知を超えた雰囲気がある（怖すぎない） |

**採用の目安**: A と B が ○、かつ C〜G の合計が 7 点以上（10 点満点）。目安なので、F だけで採用してもよい。

## 付け方

`batch-NNN.md` の判定表に記号ごとの ○△× と判定を書く。**不採用と保留には理由を一言**添える
（例: 「C×: ガラスの体で動物が消えた」）。この一言が基準を直す材料になる。

## 見直し

3 バッチ判定するごとに、Claude で `/ip-chara` を実行して集計し、この基準を更新する
（例: 採用と不採用を分けていない項目は消す、理由によく出る言葉を項目にする）。
