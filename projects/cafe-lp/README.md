# 琥珀 KOHAKU COFFEE — カフェのランディングページ

東京・蔵前の自家焙煎スペシャルティコーヒー店という設定で組んだ、1ページ完結のLPです。
**店舗は実在しません。** LPの構成とデザインを見せるためのポートフォリオ用サンプルです。

- 公開URL: https://dxiongda441-maker.github.io/portforio/projects/cafe-lp/
- ファイル: `index.html` / `styles.css` の2つだけ。ビルド不要で、開けばそのまま動きます。

## 参考にした型

Brainの教材「歴10年のプロが発見した〝売れるLPの型〟【はじめてのLPクリエイター】」と、
同じ発行元が配信している全8回の「LP基礎講座」の流れに沿って構成しています。
講座の各回が、このページのどのブロックに対応しているかは次のとおりです。

| 講 | テーマ | 対応するブロック |
| --- | --- | --- |
| 第0講 | LPとは何か / 1ページ1目的 | ページ全体。導線は「席を予約する」1本に絞っている |
| 第1講 | リサーチ（書く前に9割決まる） | 想定読者は「出社前に静かな時間がほしい人」。全文をこの一人に向けて書いた |
| 第2講 | たった一行のコンセプト | 「珈琲と、15分の静けさ」。見出しもオファーもこの一行から派生させている |
| 第3講 | LPの設計図（構成と型） | 下記のセクション順 |
| 第4講 | 最初の3秒（ファーストビュー） | `.hero`。見出し、一行説明、CTA、実績の4点を1画面に収める |
| 第5講 | 本文の構成要素 | 共感 → コンセプト → ベネフィット → 数字 → メニュー → お客様の声 |
| 第6講 | クロージング | アクセス → FAQ → オファー → 最終CTA |
| 第7講 | 公開前チェックと改善 | 下の「確認したこと」 |

## セクションの並び

1. **ファーストビュー** — 見出し / 一行説明 / CTA2種 / 実績3点
2. **共感・問題提起** — 「こんな朝を、過ごしていませんか。」3つの状況
3. **コンセプト** — 何を売っている店なのかを言い切る
4. **選ばれる3つの理由** — ベネフィットを3枚のカードに
5. **数字** — 48時間以内 / 3カ国 / 10席 / ★4.8 の4つで裏づける
6. **メニュー** — 商品と価格。モーニングセットを一段目立たせる
7. **お客様の声** — 第三者の言葉で3件
8. **アクセス** — 住所、営業時間、席数、設備
9. **FAQ** — 来店前の不安を6つ潰す
10. **オファー＋最終CTA** — 初回来店でカヌレ1つ

スマートフォンでは画面下にCTAバーを固定し、どこまで読んでも予約に戻れるようにしています。

## つくりかた

写真素材は1枚も使っていません。ファーストビューのカップはインラインSVGで、
クレマの渦はアルキメデス螺旋を2本重ねてぼかしたものです。紙の質感は
`feTurbulence` を全面に薄くかけて出しています。

書体はGoogle Fontsから3種。見出しに Shippori Mincho、本文に Zen Kaku Gothic New、
欧文に Cormorant Garamond を当てています。

## 確認したこと

- 1440px と 390px で表示を確認。横スクロールは発生しない
- コンソールエラー、読み込み失敗ともになし
- JavaScriptはヘッダーの切り替えとフェードインだけ。切っても全文が読める
- `prefers-reduced-motion` でアニメーションを停止
- FAQは `<details>` / `<summary>` なのでJSなしで開閉する
