# Glow Log

体重・写真・肌・睡眠・筋トレを毎日記録し、トレンド体重と「評価と改善点」を自動で出す自分磨き PWA。
**記録も写真もすべて端末のブラウザ内（IndexedDB）に保存し、外部へは送らない。**

## 編集するとき

- **直したら `sw.js` の `CACHE_NAME` の版数を上げる**（`v1` → `v2`）。上げないと利用者の画面が古いまま。
- ファイルを足したら `sw.js` の `ASSETS` にも足す。
- `index.html` の CSP（`<meta http-equiv="Content-Security-Policy">`）で外部通信を禁止している。外部の CDN・API・フォントは読めない（意図どおり）。
- 確認はリポジトリ直下で `python3 -m http.server 3000` → http://localhost:3000/projects/glow-log/ 。
- 評価の文言・しきい値は `app.js` の `buildInsights()` に集まっている。

## 設計図

### 1. 海外の先行例から取り入れたもの

| 先行例 | 何をしているか | Glow Log での扱い |
| --- | --- | --- |
| Hacker's Diet（John Walker）／Happy Scale／Libra | 毎日の体重を指数平滑した「トレンド体重」で見る。日々の ±1kg は水分のブレとして無視する | **採用。** 1日10%ずつ実測に寄せる平滑化。日が空いたら空いた日数分だけ寄せる |
| MacroFactor | 体重トレンドから週あたりの変化を出し、カロリー目標を調整する | **一部採用。** 直近28日の回帰直線で「週あたり何kg」を出し、方針（増量・維持・減量）ごとに適正ペースか判定。カロリー計算はしない |
| 進捗写真アプリ（Hevy の Overlay、GainFrame、PhotoJourney、Body tracker など） | 前回の写真を半透明で重ねて同じ位置・距離で撮る（ゴーストオーバーレイ）。前後比較 | **採用。** アプリ内カメラで前回写真を重ねる（濃さ調整・タイマー3/10秒・グリッド）。比較は並べる／スライダー |
| 皮膚科の臨床写真の撮り方（標準化撮影） | 距離・場所・光を固定。柔らかい拡散光、フラッシュを避ける、標準モードで撮る | **ガイドとして採用。** 「撮影と計測のルール」に落とし込み |
| 海外の “looksmaxxing” ブーム | 見た目の最適化。中身は根拠のある部分（運動・睡眠・日焼け止め・身だしなみ）と、根拠の薄い・危険な部分（骨を叩く、極端な減量など）が混在 | **根拠のある部分だけ採用。** 習慣チェックは日焼け止め・スキンケア・姿勢・眉ヒゲ・寝る前に食べない |

### 2. 毎日の流れ（1〜2分）

1. 朝、トイレの後に体重を測って入力（タイミングは自動で「朝」）
2. 洗顔後・化粧水の前に「顔・正面／横」を撮る（前回の写真に輪郭を合わせる）
3. 夜に睡眠・筋トレ・たんぱく質・肌の調子・できたことをタップで入力
4. 週1回、同じ曜日に「体・正面／横」を撮り、「推移と評価」を見る
5. 気になれば「Claude に相談する」の文章をコピーして相談する

### 3. データの形

```text
entries（1日1件、key = "YYYY-MM-DD"）
  weight, timing(morning|evening|after-bath|other), waist, sleep,
  training(none|upper|lower|full|cardio), protein,
  habits[], skin(1-5), skinTags[], energy(1-5), note, updatedAt
photos（1枚1件、同じ日・同じ種類は上書き）
  date, slot(face-front|face-side|body-front|body-side), blob(JPEG 長辺1440px), width, height
meta["profile"]
  height, targetWeight, goal(lean-bulk|maintain|cut), proteinPerKg, sleepTarget, trainingTarget
```

### 4. 計算と判定

- **トレンド体重**：`trend += (1 − 0.9^経過日数) × (実測 − trend)`
- **週あたりの変化**：直近28日の回帰直線の傾き×7。朝の記録が4件以上あれば朝だけで計算（条件をそろえる）
- **BMI・標準体重**：トレンド体重から。標準体重は BMI22
- **評価ルール**（`buildInsights()`）：測定タイミングのばらつき／BMI 区分／方針ごとのペース（増量は週 +0.1〜0.3kg 前後を適正）／目標体重までの週数／睡眠の平均／たんぱく質（体重×g/kg）／筋トレ回数／日焼け止め／肌スコアの週比較／ヒゲ・ニキビの頻度／写真の空き日数／連続記録

### 5. プライバシーと消失対策

- 外部通信なし（CSP で禁止）。写真をサーバーに送らない
- `navigator.storage.persist()` を要求。iPhone は**ホーム画面に追加**すると消えにくい
- 設定 → 「全データを書き出す」で写真込みの JSON、「CSV」で数値だけ。週1回の書き出しを案内
