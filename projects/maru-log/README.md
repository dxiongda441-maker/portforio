# Maru Log

仕事・副業・趣味・学びの大事な習慣を、毎日 ○△× で付ける記録帳 PWA。手書き日記の重要事項（アウトプット・SNS・英語・瞑想など）をそのまま移せる。
**記録はすべて端末のブラウザ内（IndexedDB）に保存し、外部へは送らない。**仕組みは Glow Log と同じ（`docs/decisions/0011`）。

## 編集するとき

- **直したら `sw.js` の `CACHE_NAME` の版数を上げる**（`v1` → `v2`）。上げないと利用者の画面が古いまま。
- ファイルを足したら `sw.js` の `ASSETS` にも足す。
- `index.html` の CSP で外部通信を禁止している。外部の CDN・API・フォントは読めない（意図どおり）。
- 確認はリポジトリ直下で `python3 -m http.server 3000` → http://localhost:3000/projects/maru-log/ 。
- 初期の項目は `app.js` の `DEFAULT_ITEMS`。**一度でも保存した端末では、端末側の項目一覧が優先される**（初期値を変えても既存の利用者には反映されない）。
- 気づきの文言・しきい値は `app.js` の `buildInsights()` に集まっている。

## データの形

```text
days（1日1件、key = "YYYY-MM-DD"）
  marks: { [項目id]: "o" | "t" | "x" }   ← ○ / △ / ×。未記入はキー自体が無い
  memo:  { work, side, hobby, study, free }   ← 空欄はキー自体が無い
  updatedAt
  ※ マスもメモも空になった日はレコードごと消す
meta["items"]（項目の一覧。並び順＝表示順）
  [{ id, name, cat(work|side|hobby|study|mind), rule: { o, t, x }, active }]
```

## 計算

- **その日の点**：記入した項目の平均（○2・△1・×0 を 100 点満点に換算）。未記入は分母に入れない
- **達成度**：期間内で記入した日だけの同じ計算。「記入」の割合は別に出す
- **連続**：今日（未記入なら昨日）から遡って ○ か △ が続いた日数。× か未記入で途切れる
- **気づき**（`buildInsights()`）：記録の連続／記録した日の割合／達成度が高い・低い項目／前の期間から ±20 ポイント／3日続けて×／曜日の傾向（30日以上・8日以上記録したとき）
