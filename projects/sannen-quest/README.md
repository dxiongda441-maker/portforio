# 3年目の分かれ道

入社3年目の12週間を過ごし、日々の仕事を「職務経歴書に書ける実績」に変えていく選択型シミュレーションゲーム。
若手社会人の悩みのうち、調査で最も根拠が厚かった **「成長実感がない・社内で実績を残せない（3年目の壁）」** に絞って作った。

| 項目 | 内容 |
| --- | --- |
| 種類 | ゲーム（選択型シミュレーション）＋ 実績メーカー（道具） |
| 公開URL | https://dxiongda441-maker.github.io/portforio/projects/sannen-quest/ |

| オフライン対応 | なし（Service Worker なし） |

## 遊び方と、何を身につけるか

| 仕組み | 現実で身につけてほしいこと |
| --- | --- |
| 毎週の出来事（同期の転職、叱責、AI のニュース、ミス、評価面談など12件） | 迷ったときの動き方。選ぶと「解説」で、なぜそうなるかを調査とあわせて示す |
| 行動（1週3回。AI で作業を減らすと4回） | 定常業務だけでは成長実感が増えない。背伸び・AI・社外・休息の配分 |
| 実績の種 → 記録 | 成果は Before→After の数字と自分の工夫で書く。3週間記録しないと消える＝記憶は薄れる |
| 記録のミニゲーム（3択） | ★1 やったことの羅列 / ★2 結果はあるが数字か手段が無い / ★3 工夫＋数字 |
| エンディング7種 | ★3 の実績の数・信頼・市場価値で決まる。モヤモヤ10で「勢いで退職」、2回倒れると「燃え尽き」 |
| 実績メーカー | 自分の本当の仕事を「業務：手段、Before→After」の1行にして保存・コピー |

## 解説に使った調査（数値は公表値。動画などに転用するときは原典で確認すること）

- 離職意向が高まるのは入社3年目：リクルートマネジメントソリューションズ「若手・中堅社員の組織適応に関する現状把握調査（2025）」
- 「働きやすいが成長できない」と感じる若手 40.3%：アデコ（2023年12月調査）
- 成長には仕事の質的負荷が必要：古屋星斗『ゆるい職場』
- 20代会社員の多くが半年以上退職を迷う：Wandering Seagull（2025）
- AI を仕事で使う20代の約6割が周囲に言わずに使う：ITプロパートナーズ（2025）
- 20代転職希望者の 63.5% が生成AIを利用：学情
- AI 導入企業で若手採用が減ったという研究：第一生命経済研究所のレポートが紹介したハーバード大学の研究
- 若年層ほど上司の叱責でストレスが高まりやすい：パーソル総合研究所（2025）
- 20代会社員の7割以上が孤独を感じることがある：東京シェアハウス
- 社会人1〜3年目の 72.0% が連休明けに仕事が憂うつになることがある：（2025年3〜4月、300名調査）

## 編集するときの注意

- 出来事は1週1件。`EVENTS` の順番がそのまま第1〜12週になる。
- 実績の書き方の選択肢は、**★3 だけが長くならないよう**長さをそろえる（読まずに当てられないように）。
- 画面は `h()` で組み立て、文字は `textContent` で入れる。利用者の入力を扱うので `innerHTML` は使わない。
- 保存データの形を変えたら `STORAGE_KEY` の版数を上げる（古い保存を読んで壊れないように）。
