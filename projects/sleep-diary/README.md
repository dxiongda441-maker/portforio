# ねむり日誌

不眠の認知行動療法（CBT-I）で使う**睡眠日誌**を2週間つけ、睡眠効率と「眠る時間の目安」を出すセルフケア PWA。
睡眠ジャンルで発信してリスト（メール登録）を集めるときの**無料の入口**として作った（`docs/decisions/0015`）。
**記録はすべて端末のブラウザ内（IndexedDB）に保存し、外部へは送らない。**仕組みは Maru Log と同じ。

| 画面 | できること |

## 編集するとき

- **直したら `sw.js` の `CACHE_NAME` の版数を上げる**（`v1` → `v2`）。
- ファイルを足したら `sw.js` の `ASSETS` にも足す。
- `index.html` の CSP で外部通信を禁止している。外部の CDN・API・フォントは読めない（意図どおり）。
- **メール登録の導線は `app.js` 冒頭の `SIGNUP_URL`。** 空のあいだは完成カードに「準備中」と出る。
  登録フォーム（外部サービス）の URL を入れるとボタンになる。リンクで移動するだけなので CSP は変えなくてよい。
- 目安の下限・上限・調整幅は `app.js` 冒頭の `MIN_WINDOW`（6時間）・`MAX_WINDOW`・`STEP`（15分）。
  **下限を6時間より下げない**（臨床では医師の管理下で5時間前後まで縮めることがあるが、これはセルフケア用）。
- はじめる前の確認の項目は `SAFETY`。`crisis: true` の項目に当てはまると相談窓口を表示する。
- 文言で「治る」「治療する」など効果をうたわない（医療機器扱いになるおそれ。0015）。
- 確認はリポジトリ直下で `python3 -m http.server 3000` → http://localhost:3000/projects/sleep-diary/ 。

## データの形

```text
nights（1晩1件、key = 起きた日の "YYYY-MM-DD"）
  bed / lightsOff / finalWake / outOfBed: "HH:MM"
  sol（寝つくまで・分）/ waso（夜中に起きていた合計・分）/ wakeups（回）/ quality（1-5）
  tags: ["caffeine" | "alcohol" | "nap" | "exercise" | "screen" | "stress"]
  note（200字まで）/ updatedAt
meta["settings"]
  { onboarded, wakeTarget "HH:MM",
    safety: { answers: { [id]: true }, flagged, crisis, checkedAt },
    plan: { window: 分, wake: "HH:MM", start: "YYYY-MM-DD" } | null }
```

## 計算（Carney 2012 コンセンサス睡眠日誌に準拠）

- 時刻は「起きた日の 0:00」からの分に直す。**12:00 以降は前の晩**とみなす（夜勤の人は確認で除外している）
- **床にいた時間** = ⑦床から出た − ①床に入った
- **眠っていた時間** = ⑥最後に目覚めた − ②消灯 − ③寝つくまで − ⑤夜中に起きていた
- **睡眠効率** = 眠っていた ÷ 床にいた。期間の値は夜ごとの平均ではなく合計どうしの比
- **眠る時間の目安**（`buildPlan()`）：直近7日で5夜以上あれば出す
  - 初回：平均睡眠時間を15分単位で切り下げ（下限6時間、上限は今の床上時間）。効率が90%以上なら今の床上時間のまま
  - 試して7日たち5夜以上たまったら：効率90%以上 → +15分、85〜90% → そのまま、85%未満 → −15分（下限6時間）
  - 床に入る時刻 = 起床時刻 − 目安
- **気づき**（`buildInsights()`）：効率85%未満／寝つき30分超／中途覚醒30分超／起床時刻のばらつき45分超／
  行動タグの有無で効率に3pt以上の差（両側3夜以上。因果ではなく記録上の傾向として表示）
