# 関心プロファイル

このファイルが選別の基準です。**ここを書き換えることが、このツールを自分専用にする唯一の作業です。**
記事は「一般的に面白いか」ではなく「ここに書かれたテーマにどれだけ刺さるか」でスコアされます。

## 私が発信しているテーマ

- 個人がAIを使って小さなプロダクトを作り、収益化するまでの実践
- Claude / LLM を使った開発の具体的なやり方（プロンプト、ワークフロー、失敗談）
- ノーコード・ローコードと、非エンジニアがコードを書けるようになる流れ
- 個人開発者のマネタイズ事例（SaaS、有料ニュースレター、デジタル商品）
- 退屈だが儲かるニッチ市場の発見と、そこへのアプローチ

## 追っているキーワード

- Claude
- Anthropic
- 個人開発
- インディーハッカー
- AIエージェント
- ニュースレター収益化
- 自動化ワークフロー

## 読者に向けて書いている媒体

- Substack: 週1本の長文。事例と手順を深く掘る。
- X: 1日数本。数字・驚き・具体名が入るものが伸びる。
- Obsidian: 自分用のネタ帳。あとで記事にする素材を貯める。

## 興味がないもの

- 芸能・スポーツ・政局のニュース
- 大企業の人事異動や決算の数字だけの記事
- 具体的なやり方が書かれていない「AIで世界が変わる」系の抽象論
- 未検証の噂やリーク情報
